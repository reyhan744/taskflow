# راهنمای نصب و راه‌اندازی TaskFlow

## ۱. پیش‌نیازها

| مورد | حداقل | توصیه‌شده |
|------|-------|-----------|
| WordPress | 6.0 | آخرین نسخهٔ پایدار |
| PHP | 7.4 | 8.1 تا 8.3 |
| MySQL / MariaDB | MySQL 5.7+ / MariaDB 10.3+ | هر نسخهٔ سازگار با وردپرس |
| مرورگر | نسخه‌های پشتیبانی‌شدهٔ وردپرس | Chrome / Firefox / Edge / Safari آخرین |

- افزونهٔ **مستقل** است: به قالب خاصی (Zephyr/Impreza یا غیره) و هیچ افزونهٔ دیگری وابسته نیست.
- نسخه‌های دقیق محیط آزمایش این پروژه: WordPress 6.9 + PHP 8.3.32 + SQLite drop-in 2.1.15 + Vue.js 3.5.13 (جزئیات در docs/TESTING.md).

## ۲. نصب از طریق پیشخوان (روش پیشنهادی)

1. وارد پیشخوان وردپرس شوید (با حساب مدیر).
2. مسیر **Plugins → Add New Plugin → Upload Plugin** را باز کنید.
3. فایل `taskflow.zip` (از بخش Releases مخزن) را انتخاب و **Install Now** بزنید.
4. روی **Activate Plugin** کلیک کنید.
5. در منوی سمت راست پیشخوان روی **TaskFlow** کلیک کنید — برنامه باز می‌شود.

## ۳. نصب دستی (FTP/مدیر فایل)

1. محتوای `taskflow.zip` را در مسیر `wp-content/plugins/` استخراج کنید؛ نتیجه باید `wp-content/plugins/taskflow/taskflow.php` باشد.
2. از **Plugins** صفحهٔ مدیریت، TaskFlow را **Activate** کنید.

## ۴. اولیه‌سازی در چند دقیقه

پس از فعال‌سازی به‌طور خودکار این‌ها انجام شده است:

- ساخت ۱۱ جدول `wp_taskflow_*` با dbDelta
- ثبت قابلیت‌های نقش‌ها (مدیر: مدیریت کامل، ویرایشگر: مدیریت وظایف همه، نویسنده/مشارکت‌کننده: وظایف خودشان)
- تنظیمات پیش‌فرض (ارز USD، ۱۰ آیتم در صفحه، اعلان‌ها روشن، حذف داده هنگام uninstall خاموش)

**پیشنهاد برای ارزیابی سریع:** در **TaskFlow → Settings → Create DEMO data (MOCK/DEMO)** روی دکمه بزنید تا چند وظیفه/پروژه/برچسب نمایشی با برچسب صریح MOCK ساخته شود.

## ۵. نقش‌ها و دسترسی‌ها

| نقش | دسترسی |
|-----|--------|
| Administrator | همه‌چیز: تنظیمات، خروجی/ورود داده، پرداخت Mock، همهٔ وظایف |
| Editor | همهٔ وظایف همهٔ کاربران + مدیریت پروژه/برچسب + ایمیل Mock |
| Author / Contributor | ایجاد وظیفه + دیدن/ویرایش وظایف خود و وظایف محول‌شده (مسئول فقط تغییر وضعیت) |
| سایر نقش‌ها | در تنظیمات می‌توانید دسترسی «وظایف خود» را به هر نقشی بدهید (Who can use TaskFlow) |

## ۶. آزمایش Mockها

- **پرداخت:** تب **Payments (Mock)** → New simulated payment → مبلغ و نتیجهٔ شبیه‌سازی‌شده (success / failed / pending) → برای pending دکمه‌های Finalize. همه‌جا برچسب MOCK/DEMO.
- **ایمیل:** تب **Mail (Mock)** → Compose (ثبت در Outbox) و Simulate incoming e-mail (ثبت در Inbox). تخصیص وظیفه به‌طور خودکار یک ایمیل MOCK در Outbox می‌سازد.

## ۷. خروجی/ورود داده

- خروجی: **Settings → Data → Export tasks (CSV/JSON)** — CSV با BOM برای نمایش درست فارسی در Excel.
- ورود: **Settings → Data → Import** — فایل یا متن CSV با سرستون `title,description,status,priority,due_date,project,tags,assignee` — قالب نمونه از «Download CSV template».

## ۸. حذف افزونه و داده‌ها

- **غیرفعال‌سازی** فقط قابلیت‌های نقش‌ها را برمی‌دارد؛ داده‌ها سر جایشان می‌مانند.
- **حذف (Delete):** اگر در تنظیمات «Delete all data when the plugin is deleted» روشن باشد، همهٔ جدول‌ها و تنظیمات پاک می‌شوند؛ در غیر این صورت داده‌ها برای نصب مجدد حفظ می‌شوند. این رفتار در تنظیمات و در `uninstall.php` مستند است.

## ۹. عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| صفحهٔ TaskFlow خالی می‌ماند | کش مرورگر را پاک کنید (Ctrl+Shift+R)؛ مطمئن شوید جاوااسکریپت فعال است |
| خطای 403 در برخی کاربران | طبیعی است — نقش بدون قابلیت TaskFlow اجازه ندارد؛ نقش را در تنظیمات اضافه کنید |
| تاریخ‌ها شمسی نیستند | زبان کاربر (Profile → Language) را روی فارسی بگذارید |
| فونت/چیدمان به‌هم‌ریخته | افزونه‌های کش را موقتاً غیرفعال کنید |
| خطای دیتابیس هنگام نصب | دسترسی نوشتن `wp-content` و نسخهٔ MySQL/MariaDB را بررسی کنید |

## ۱۰. نصب از سورس (توسعه‌دهندگان)

```bash
git clone https://github.com/reyhan744/taskflow.git
cd taskflow
# تست‌ها (بدون نیاز به وردپرس):
curl -sSL -o phpunit.phar https://phar.phpunit.de/phpunit-10.phar
php phpunit.phar -c phpunit.xml.dist
```
