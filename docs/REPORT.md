## ۱. خلاصهٔ معماری و علت انتخاب‌ها

- **بک‌اند:** PHP 7.4+ سازگار تا 8.3 روی APIهای استاندارد وردپرس — REST API با `permission_callback` برای تک‌تک مسیرها، Nonce، Capability، پاکسازی ورودی، Escape خروجی و `$wpdb->prepare()` در تمام کوئری‌ها.
- **فرانت‌اند: Vue.js 3.5.13** — علت انتخاب: (۱) مدرن و به‌روز است در حالی که AngularJS از ۲۰۲۱ پشتیبانی رسمی ندارد؛ (۲) نسخهٔ `vue.global.prod.js` داخل بسته جاسازی شده تا نصب روی هر هاستی **بدون Node/npm و Build** ممکن باشد؛ (۳) اکوسیستم و خوانایی کد برای نگهداری بلندمدت بهتر است. SPA فقط مصرف‌کنندهٔ API امن است؛ هیچ منطق کسب‌وکار یا دسترسی‌ای در سمت کلاینت تصمیم گرفته نمی‌شود.
- **دیتابیس:** MySQL از طریق `wpdb` با ۱۱ جدول اختصاصی (`dbDelta` + نسخهٔ پایگاه داده). جدول اختصاصی به‌جای CPT/Meta برای فیلترهای مرکب، ایندکس واقعی و JOIN تمیز انتخاب شد.
- **لایه‌بندی:** REST Controllers → Services (منطق) → Repositories (SQL خالص) → wpdb. سرویس‌های Mock به‌صورت Adapter با قرارداد مشخص پیاده شده‌اند تا در آینده با درگاه/ایمیل واقعی فقط همان کلاس جایگزین شود. جزئیات کامل: `docs/ARCHITECTURE.md`.

## ۳. شیوهٔ آزمایش Mockها

**پرداخت (Mock Gateway Adapter):** تب «Payments (Mock)» → دکمهٔ «New simulated payment» → ثبت مبلغ و انتخاب نتیجهٔ شبیه‌سازی (success / failed / pending) → ثبت تراکنش ساختگی با شناسهٔ `TFMOCK-XXXXXXXX`، زمان و وضعیت → برای تراکنش‌های pending دو دکمهٔ نهایی‌سازی (موفق/ناموفق) → جمع‌های هر وضعیت بالای جدول به‌روزرسانی می‌شود. هیچ درگاه، پول یا اطلاعات بانکی واقعی در کار نیست و همهٔ پیام‌ها/نماها با عبارت صریح **MOCK/DEMO** برچسب خورده‌اند.

**ایمیل (Mock Mailer):** تب «Mail (Mock)» شامل دو صندوق:
- **Outbox:** با «Compose» ایمیل شبیه‌سازی‌شده ثبت می‌شود (گیرنده، موضوع، متن، نتیجهٔ ارسال، زمان). ضمناً تخصیص وظیفه و منشن به‌طور خودکار ایمیل MOCK تولید می‌کند.
- **Inbox:** با «Simulate incoming e-mail» پیام ورودی ساختگی ثبت می‌شود (فرستنده، موضوع، متن، زمان) با حالت خوانده‌نشده و دکمهٔ Mark as read.
اتصال واقعی به SMTP/IMAP وجود ندارد؛ فیلتر `taskflow_mock_mailer_passthrough` فقط به‌عنوان نقطهٔ اتصال آینده تعبیه شده و پیش‌فرض خاموش است.

## ۴. تست‌ها و نتایج

- **PHPUnit: ۶۱ تست / ۲۱۳ اظهار — همه سبز** (CRUD، مجوزها و مالکیت، جستجو/فیلتر/مرتب‌سازی، Kanban/resequence، داشبورد، پرداخت Mock، ایمیل Mock، اعلان‌ها، اکسپورت/ایمپورت، نظرات/منشن، تایمر، تنظیمات/اعتبارسنجی). اجرا: `php phpunit.phar -c phpunit.xml.dist` — بدون نیاز به وردپرس/MySQL.
- **E2E روی وردپرس خام: ۵۶/۵۶ بررسی سبز** (`tests/e2e.php` — کل مسیرهای REST با ۴ نقش کاربری) و `debug.log` بدون هیچ هشدار/خطای PHP.
- **CI:** GitHub Actions روی PHP 8.1/8.2/8.3 (php -l همهٔ فایل‌ها + کل مجموعهٔ تست).
- جزئیات و خروجی‌های واقعی: `docs/TESTING.md` · سناریوهای پذیرش هر قابلیت: `docs/ACCEPTANCE.md`.

## ۵. محیط آزمایش و نصب‌پذیری

- آزمایش‌شده روی **WordPress 6.9 + PHP 8.3.32** (پایگاه دادهٔ SQLite از طریق drop-in رسمی — یعنی همان لایهٔ `wpdb`؛ سازگار با MySQL/MariaDB استاندارد) + **Vue.js 3.5.13 (bundled)**.
- فعال‌سازی روی وردپرس خام بدون خطای بحرانی؛ افزونه از قالب مستقل است (بدون وابستگی به Zephyr/Impreza) و پس از تغییر قالب به کار خود ادامه می‌دهد.
- نصب: ZIP بخش Releases از طریق Plugins → Upload؛ راهنمای گام‌به‌گام: `docs/INSTALL.md`.

## ۶. امنیت

`permission_callback` + Capability + بررسی مالکیت در تک‌تک مسیرها · محدودیت دید در خودِ SQL (`visibility_sql`) · Nonce برای همهٔ درخواست‌های SPA · پاکسازی/اعتبارسنجی متمرکز ورودی‌ها (`TaskFlow_Validation`) · ORDER BY whitelist · `$wpdb->prepare()` همه‌جا · Escape خودکار خروجی Vue (بدون v-html) · عدم ثبت هرگونه رمز/Token در مخزن · حذف داده هنگام uninstall فقط با انتخاب صریح مدیر.

## ۷. محدودیت‌های شناخته‌شده و موارد قابل بهبود

1. **Kanban روی هم‌زمانی بالا:** resequence کل ستون بعد از هر جابه‌جایی برای تیم‌های بزرگ چندنفرهٔ هم‌زمان بهینه نیست؛ در نسخهٔ بعد: قفل بهینه‌شده/محاسبهٔ delta.
2. **جستجو فقط روی عنوان** (طبق صورت سوال)؛ جستجوی full-text روی توضیحات می‌تواند اضافه شود.
3. **گزارش‌های نموداری پیشرفته‌تر** (روند هفتگی و ...) فعلاً به صورت میله‌ای/حلقه‌ای ساده است.
4. **ایمیل Mock:** ورودی واقعی IMAP عمداً پیاده نشده (خارج از دامنهٔ چالش)؛ فقط شبیه‌سازی.
5. **چند‌سایتی (Multisite):** آزمایش اختصاصی multisite انجام نشده است.
6. **i18n:** ترجمهٔ کامل فقط fa_IR فراهم است (POT برای سایر زبان‌ها آماده است).
